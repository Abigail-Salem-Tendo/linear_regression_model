# Linear Regression Model

Regression model, FASTAPI service and one-page Flutter app.

## Structure
- ``summative/linear_regression/multivariate.ipynb``: model training notebook
- ``summative/API``: FastAPI service (``prediction.py``, ``requiirements.txt``, ``best_model.pkl``)
- ``summative/FlutterApp/``: Flutter mobile app

## Setup

``cd summative``

``uv sync``
